使用说明

五步上手，几分钟就够。

  1. 1

    安装

    在下载页下载安装包；或在终端粘贴一行命令。

    macOS / Linux：curl -fsSL https://pixotap.plutokeating.beer/install | bash
Windows（PowerShell）：irm https://pixotap.plutokeating.beer/install.ps1 | iex

    首次打开如被系统拦截：macOS 右键应用选“打开”；Windows 点“更多信息”，再选“仍要运行”。

  2. 2

    首次打开，按提示授权

    macOS 需要“屏幕录制”，建议同时开启“辅助功能”；相机可选。权限随时可在系统设置里关闭。

  3. 3

    开始工作，离开前记下断点

    在灵动岛（或工作台）选好项目，点“开始”。要离开时点“记下断点”。只有你点击开始后才会记录。

  4. 4

    回来时，一眼接回进度

    打开同一个项目，会看到上次停在哪里、这次先做什么。

  5. 5

    （可选）登录账号

    不登录也能使用。需要管理设备与数据时，在设置里点“登录”，在浏览器中完成授权。前往账号页

常见问题

我需要账号吗？

不需要。账号是可选的，只支持邮箱加密码登录，用于管理资料、已授权设备、同意设置、数据导出与注销。

数据保存在哪里？会上传吗？

默认只保存在你的设备上：macOS 在 ~/Library/Application Support/PixoTap，Windows 在 %LocalAppData%\PixoTap，Linux 在 ~/.local/share/PixoTap。截图原图、照片、原文件内容和剪贴板正文不会上传。详见隐私政策。

AI 功能需要什么？

需要你自己的 DeepSeek API 密钥。没有密钥或断网时，仍会生成本地交接摘要，联网后继续分析。

怎么卸载？

macOS：把应用拖进废纸篓。Windows：在“设置 > 应用”中卸载。Linux：运行高级里的卸载命令。卸载不会删除你的数据目录。

怎么停止记录？

点“记下断点”即可；隐藏入口或退出程序也会停止记录。

高级

校验下载文件（SHA-256）

下载页每个安装包下的“SHA-256”给出校验值，下载后在终端比对：

shasum -a 256 <文件>                       # macOS
sha256sum <文件>                           # Linux
Get-FileHash -Algorithm SHA256 <文件>      # Windows（PowerShell）

Linux

系统要求：Ubuntu 24.04 或更新（x86_64）。一行命令不需要 root，安装到 ~/.local，重复运行即升级。需要的运行库：

sudo apt install libwebkit2gtk-4.1-0 libayatana-appindicator3-1 tesseract-ocr tesseract-ocr-eng tesseract-ocr-chi-sim

卸载（保留 ~/.local/share/PixoTap 中的数据）：

curl -fsSL https://pixotap.plutokeating.beer/install | bash -s -- --uninstall

保存 AI 密钥需要系统的 Secret Service（gnome-keyring 或 KWallet）。

Windows

推荐 setup.exe：每用户安装，不需要管理员权限。使用 ZIP 时请完整解压后运行 PixoTap.exe。

Documentation

Five steps; a few minutes is enough.

  1. 1

    Install

    Download the installer from the download page, or paste one command into a terminal.

    macOS / Linux: curl -fsSL https://pixotap.plutokeating.beer/install | bash
Windows (PowerShell): irm https://pixotap.plutokeating.beer/install.ps1 | iex

    If the system blocks the first launch: on macOS right-click the app and choose Open; on Windows click More info, then Run anyway.

  2. 2

    Open it and grant access

    macOS needs Screen Recording and works best with Accessibility; the camera is optional. You can turn any permission off in system settings at any time.

  3. 3

    Start working, mark a checkpoint when you leave

    Pick a project in the island (or the workbench) and press Start. When you step away, press Mark checkpoint. Nothing is recorded until you press Start.

  4. 4

    Come back and pick up your progress

    Open the same project to see where you left off and what to do next.

  5. 5

    (Optional) Sign in

    Everything works without an account. To manage devices and data, choose Sign in in Settings and finish authorization in your browser. Go to the account page

FAQ

Do I need an account?

No. Accounts are optional, use email and password only, and are for managing your profile, authorized devices, consents, data export and deletion.

Where is my data stored? Is it uploaded?

On your device by default: ~/Library/Application Support/PixoTap on macOS, %LocalAppData%\PixoTap on Windows, ~/.local/share/PixoTap on Linux. Original screenshots, photos, file contents and clipboard text are never uploaded. See the Privacy Policy.

What does AI need?

Your own DeepSeek API key. Without a key, or offline, a local hand-off summary is still produced and analysis continues once you are online.

How do I uninstall?

macOS: drag the app to the Trash. Windows: remove it in Settings > Apps. Linux: run the uninstall command under Advanced. Your data folder is kept.

How do I stop recording?

Press Mark checkpoint; hiding the entry point or quitting the app also stops recording.

Advanced

Verify a download (SHA-256)

Each installer on the download page has a SHA-256 value under it. After downloading, compare it in a terminal:

shasum -a 256 <file>                       # macOS
sha256sum <file>                           # Linux
Get-FileHash -Algorithm SHA256 <file>      # Windows (PowerShell)

Linux

Requires Ubuntu 24.04 or newer (x86_64). The one-line command needs no root, installs under ~/.local, and running it again upgrades. Runtime libraries:

sudo apt install libwebkit2gtk-4.1-0 libayatana-appindicator3-1 tesseract-ocr tesseract-ocr-eng tesseract-ocr-chi-sim

Uninstall (your data in ~/.local/share/PixoTap is kept):

curl -fsSL https://pixotap.plutokeating.beer/install | bash -s -- --uninstall

Saving an AI key needs the system Secret Service (gnome-keyring or KWallet).

Windows

Prefer setup.exe: per-user install, no administrator rights. With the ZIP, extract everything and run PixoTap.exe.
