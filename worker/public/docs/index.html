使用说明

PIXO TAP 帮你在多项长期任务之间切换后接回进度。本页说明如何安装、需要哪些权限、数据放在哪里，以及常见问题。

当前状态。 PIXO TAP 仍在开发中。Windows 版处于开发与试用阶段；Mac 版仍处于实验阶段，暂不提供下载；Linux 为早期版本，可一键安装；Android、iOS 尚未发布；实体桌宠硬件仍是概念；网站上的交互演示和 Web 原型中的“识别”是模拟，不会读取你的设备。下载页没有已发布版本时会如实显示空状态。各平台的版本号相互独立，以下载页为准。

安装

先到下载页获取安装包，并按页面说明核对 SHA-256 校验值。试用包目前没有 Windows 代码签名，系统可能给出“未知发布者”的提示，请只使用来自下载页的文件。

macOS

Mac 版仍处于实验阶段，暂不提供下载。

Windows

  • 系统要求：Windows 11 x64，或 Windows 10 x64 2004（build 19041）及以上。当前实际验收环境是 Windows 11，其它版本的兼容性尚待验证。
  • 推荐下载 setup.exe 安装程序：双击即装，每用户安装到 %LocalAppData%\Programs\PixoTap，不需要管理员权限，并创建开始菜单与桌面快捷方式；卸载会保留 %LocalAppData%\PixoTap 里的数据。安装程序缺少 VC++ 运行库时会请求一次提权来安装它。
  • 使用 ZIP 时：完整解压，保留 Assets、x64、tessdata、Licenses 等目录，再打开 PixoTap.exe。不要直接在压缩包里运行，也不要只复制 EXE。
  • 安装包与压缩包都已附带 .NET 运行时。文字识别（OCR）另需 Microsoft Visual C++ v14 x64 运行库；setup.exe 会在缺少时安装，使用 ZIP 时请先安装微软官方运行库再重新打开程序，安装可能需要管理员权限。

Linux

  • 系统要求：x86_64，Ubuntu 24.04 或更新版本（glibc 2.39+）。不支持 Alpine 等 musl 系统；arm64 暂无构建。
  • 在终端运行一键安装命令（只需要 curl、tar、sha256sum，不需要 root，脚本不会调用 sudo）：
    curl -fsSL https://pixotap.plutokeating.beer/install | bash
  • 脚本在运行时通过 GitHub 公开 API 找到包含 Linux 安装包的最新发布，用同一发布里的 SHA256SUMS.txt 校验，校验失败会中止且不改动已安装的版本。重复运行即升级；加 --dry-run 可只预览不安装，加 --stable-only 忽略预发布版本。
  • 安装位置：程序在 ~/.local/share/pixotap，命令 pixotap 链接到 ~/.local/bin（若该目录不在 PATH 中，脚本会提示），桌面入口与图标在 ~/.local/share。安装后在应用菜单搜索 PixoTap，或在终端运行 pixotap。
  • 运行库（脚本只提示，不会自动安装）：libwebkit2gtk-4.1、libayatana-appindicator3，以及文字识别用的 tesseract-ocr 与中文语言包。Ubuntu / Debian：
    sudo apt install libwebkit2gtk-4.1-0 libayatana-appindicator3-1 tesseract-ocr tesseract-ocr-eng tesseract-ocr-chi-sim
    保存 AI 服务密钥还需要系统的 Secret Service（如 gnome-keyring 或 KWallet）。
  • 卸载（保留 ~/.local/share/PixoTap 中的你的数据）：
    curl -fsSL https://pixotap.plutokeating.beer/install | bash -s -- --uninstall
  • Linux 版目前是早期版本。已知限制：只有 x86_64 构建；在 GNOME Wayland 下读取不到前台窗口与应用信息，记录里会如实写“窗口信息不可用”；本版摄像头不可用，结束照片不会生成；剪贴板在 Wayland 下不记录；桌宠在 Wayland 下不保证置顶，会降级为普通小窗；系统托盘在 GNOME 上需要 AppIndicator 扩展（Ubuntu 默认带），缺少时主窗口仍可正常使用。

基本使用

macOS

  • 默认入口是屏幕顶部的“灵动岛”：悬停展开，选择项目后点“继续工作”或“开始记录”，结束时点“保存断点”。可在设置中切换为桌宠入口。
  • 只有你明确点击开始后才会记录；浏览、切换页签、取消都不会开始记录。
  • “专注”提供 25、45、60 分钟计时；“暂放”最多保存 20 个本机文件引用，不会移动或复制原文件。
  • “聊一聊”打开 AI 对话，需要你自己的 DeepSeek 密钥；没有密钥时仍会生成本地交接摘要。
  • 菜单栏的笑脸始终可以召回、隐藏入口或退出。

Windows

  • 从入口或托盘打开工作台，新建项目或子项目，选中后点击开始记录；在授权窗口里逐项选择活动信息、文件路径、截图/OCR 和结束照片。
  • 点击“保存断点”结束会话，恢复笔记会先保存在本机，再等待或执行在线分析。
  • 在入口上按 Alt+F4 会停止记录并隐藏入口，可从托盘再次显示；完全退出请用托盘菜单的“退出”。

Linux

  • 流程与 macOS、Windows 一致：只有你明确同意并点击开始才会记录；浏览项目、设置不会记录；所有窗口都隐藏或退出时停止记录。点击“保存断点”结束会话，恢复笔记先保存在本机，再等待或执行在线分析。
  • 没有密钥或断网时，本地内容会保留，重启后继续处理。

恢复笔记

结束一次会话后，回到同一个项目会看到固定的四段：本次完成、推进到这里、当前卡点、下次先做。恢复内容不包含材料路径或网页地址。

权限

所有权限都可以随时在系统设置中关闭；拒绝权限时，对应功能不可用，其它功能仍可使用。

权限用于说明
屏幕录制（macOS）开始和结束时截取前台窗口，并在本机做文字识别截图在本机处理；相同或近似画面会去重；密码工具、已识别的隐私浏览窗口和敏感路径默认跳过。
辅助功能（macOS）读取当前窗口标题、浏览器页面标题、应用公开的本地文件路径不开启也能使用，只是线索更少。
相机结束会话时拍一张现场照片，帮助你回忆macOS 在首次结束会话时请求；Windows 需要系统“允许桌面应用访问摄像头”。拒绝、无设备或取不到有效画面时不会生成照片。
文件与剪贴板记录新建、下载、修改、移动的文件名与路径；剪贴板变化剪贴板只记录变化类型和前台应用，不保存正文。
屏幕截图（Linux）开始和结束时截取屏幕通过系统的 XDG Desktop Portal，每次需在系统弹窗中授权，且只能截整个屏幕；被拒绝或没有门户时，本次会话不截图，活动与文件记录继续，界面会如实提示。系统是否记住授权取决于桌面版本。
文件监听（Linux）记录桌面、文稿、下载、图片、视频、音乐目录里的文件活动只在你授权并开始记录后才监听；隐藏、敏感、临时与生成类文件按规则排除。

数据存放位置

  • macOS：~/Library/Application Support/PixoTap/Projects/<项目 ID>/暂存/<会话 ID>。原文件不会被搬动或复制。
  • Windows：%LocalAppData%\PixoTap，包括 Projects、设置和 IslandShelf\references.json。备份时请先退出程序，再复制整个目录。
  • Linux：$XDG_DATA_HOME/PixoTap，默认是 ~/.local/share/PixoTap。卸载脚本会保留这个目录。
  • DeepSeek 密钥：macOS 保存在系统钥匙串；Windows 由系统凭据保护保存；Linux 保存在系统 Secret Service（gnome-keyring 或 KWallet）。没有 Secret Service 时无法保存密钥，不会改存为明文文件。都不会写入项目文件或应用包。
  • 删除应用不会自动删除工作数据；如需清除，请在退出程序后自行删除上述目录。

隐私承诺

  • 本地优先：不登录、不联网也能记录和恢复。
  • 截图原图、结束照片、原文件内容、剪贴板文字正文不会上传。
  • 只有在你配置了自己的密钥并主动触发分析时，本机识别出的 OCR 文字、活动时间线和应用名称才会发送给 AI 服务（目前为 DeepSeek）。OCR 文字可能含敏感信息，请按项目内容决定是否授权。
  • 使用遥测默认关闭；数据同步是可选功能，客户端目前尚未开放。开启前需要你明确同意“数据同步”（可随时撤回），同步内容端到端加密，服务器只保存密文。
  • 账号是可选的，由自托管的 Logto 登录服务管理，只支持邮箱加密码登录；登录后客户端不会自动上传你的数据。

完整说明见隐私政策（草案）。

常见问题

我需要账号吗？

不需要。不登录也能使用客户端的全部本地功能，登录后也不会自动上传你的数据。账号是可选的，用于管理资料、已授权设备、同意设置、数据导出与注销。登录只支持邮箱加密码：注册时用邮箱验证码验证，忘记密码时用邮箱验证码重置；不支持手机号登录和 Apple、Google、GitHub 等第三方登录，也没有多因素验证。Linux、Android 和 Windows 客户端可在设置里点“登录”，在浏览器里完成设备授权；macOS 客户端暂未接入登录。管理账号请到账号页面。

为什么下载页没有可下载的版本？

说明该平台还没有发布，或所有发布都还是预发布版本（请在下载页打开“显示测试版”）。页面会如实显示“暂时没有可下载的版本”，不会显示虚构的版本号。请稍后再来。

Windows 提示“未知发布者”怎么办？

程序目前没有代码签名，系统可能弹出 SmartScreen 提示。请核对下载页给出的 SHA-256 后再运行。

AI 功能需要什么？

需要你自己的 DeepSeek API 密钥，并自行承担相应的服务费用与条款。没有密钥或断网时，仍会生成本地交接摘要，待处理的分析在联网后继续。

Linux 上提示缺少库或没有 Secret Service 怎么办？

按“安装”一节安装对应的运行库；需要保存 AI 密钥时，请安装并解锁 gnome-keyring 或 KWallet。没有 Secret Service 时本地记录不受影响，只是无法保存密钥与登录令牌。

如何停止记录？

点击“保存断点”即可；隐藏入口或退出程序也会停止记录。在 macOS 上，也可以从菜单栏笑脸结束。

有 Linux、Android、iOS 版本吗？实体桌宠呢？

Linux 有早期版本（仅 x86_64，见“安装”一节的一键安装与已知限制）。Android、iOS 尚未发布，网站上也不提供下载。实体桌宠硬件仍是概念，没有硬件时软件也能独立使用。

如何删除我的数据？

本机数据：退出程序后删除上文“数据存放位置”中的目录。账号数据导出与注销请在账号中心进行。

发现说明与实际不符？以实际软件行为为准，欢迎反馈（联系方式待补充）。

Install

Get the installer from the download page and verify its SHA-256 checksum as described there. The Windows trial build currently has no code signing, so the system may warn about an unknown publisher. Only use files from the download page.

macOS

The Mac app is still experimental, with no download for now.

Windows

  • Requirements: Windows 11 x64, or Windows 10 x64 version 2004 (build 19041) or later. The tested environment is Windows 11; other versions still need verification.
  • Recommended: the setup.exe installer. Double-click to install per user into %LocalAppData%\Programs\PixoTap with no administrator rights, with Start menu and desktop shortcuts; uninstalling keeps your data in %LocalAppData%\PixoTap. If the VC++ runtime is missing it asks for elevation once to install it.
  • With the ZIP: extract the whole archive, keeping folders such as Assets, x64, tessdata and Licenses, then open PixoTap.exe. Do not run it from inside the archive or copy the EXE alone.
  • Both packages ship with the .NET runtime. Text recognition (OCR) also needs the Microsoft Visual C++ v14 x64 runtime; setup.exe installs it when missing, with the ZIP install Microsoft's official runtime and reopen the app (administrator rights may be required).

Linux

  • Requirements: x86_64, Ubuntu 24.04 or newer (glibc 2.39+). musl systems such as Alpine are not supported; there is no arm64 build yet.
  • Run the one-line installer in a terminal (needs only curl, tar and sha256sum; no root, and the script never calls sudo):
    curl -fsSL https://pixotap.plutokeating.beer/install | bash
  • At run time the script uses the public GitHub API to find the newest release that contains the Linux package and verifies it against that release's SHA256SUMS.txt; on a mismatch it aborts and leaves any installed version untouched. Run it again to upgrade; add --dry-run to preview only, or --stable-only to ignore pre-releases.
  • Locations: the app goes to ~/.local/share/pixotap, the pixotap command is linked into ~/.local/bin (the script warns if that directory is not on PATH), and the desktop entry and icons go under ~/.local/share. Afterwards search for PixoTap in your app menu, or run pixotap.
  • Runtime libraries (the script only prints hints, it installs nothing): libwebkit2gtk-4.1, libayatana-appindicator3, plus tesseract-ocr with the Chinese language pack for text recognition. On Ubuntu / Debian:
    sudo apt install libwebkit2gtk-4.1-0 libayatana-appindicator3-1 tesseract-ocr tesseract-ocr-eng tesseract-ocr-chi-sim
    Saving an AI service key also needs the system Secret Service (such as gnome-keyring or KWallet).
  • Uninstall (keeps your data in ~/.local/share/PixoTap):
    curl -fsSL https://pixotap.plutokeating.beer/install | bash -s -- --uninstall
  • The Linux app is an early release. Known limitations: x86_64 builds only; on GNOME Wayland the foreground window and app cannot be read, so records honestly say "window info unavailable"; the camera is not available in this release and no closing photo is made; the clipboard is not recorded on Wayland; the desk pet is not guaranteed to stay on top on Wayland and falls back to a normal small window; on GNOME the tray needs the AppIndicator extension (included in Ubuntu), and without it the main window still works.

Basics

macOS

  • The default entry is the "Dynamic Island" at the top of the screen: hover to expand, pick a project, then click Continue work or Start recording; click Save checkpoint when you finish. You can switch to the desktop-companion entry in settings.
  • Nothing is recorded until you explicitly start; browsing, switching tabs and cancelling never start recording.
  • Focus offers 25, 45 and 60 minute timers; Shelf keeps up to 20 references to local files without moving or copying the originals.
  • Chat opens the AI conversation and needs your own DeepSeek key; without a key a local hand-off summary is still generated.
  • The smiley in the menu bar can always recall or hide the entry, or quit.

Windows

  • Open the workspace from the entry or the tray, create a project or sub-project, select it and start recording; in the consent window choose item by item: activity info, file paths, screenshots/OCR and the closing photo.
  • Click Save checkpoint to end the session; the recovery note is saved locally first, then online analysis is awaited or run.
  • Alt+F4 on the entry stops recording and hides it; show it again from the tray. To quit completely use Quit in the tray menu.

Linux

  • The flow matches macOS and Windows: nothing is recorded until you explicitly consent and click start; browsing projects or settings records nothing; recording stops when all windows are hidden or the app quits. Click Save checkpoint to end the session; the recovery note is saved locally first, then online analysis is awaited or run.
  • Without a key or when offline, local content is kept and processing resumes after a restart.

Recovery notes

After a session ends, returning to the same project shows four fixed parts: what was done, where it got to, current blockers, and what to do first next time. Recovery notes do not include material paths or web addresses.

Where data is stored

  • macOS: ~/Library/Application Support/PixoTap/Projects/<project ID>/暂存/<session ID>. Original files are never moved or copied.
  • Windows: %LocalAppData%\PixoTap, including Projects, settings and IslandShelf\references.json. Quit the app before backing up, then copy the whole folder.
  • Linux: $XDG_DATA_HOME/PixoTap, by default ~/.local/share/PixoTap. The uninstall script keeps this folder.
  • DeepSeek key: stored in the macOS Keychain, protected by Windows credential protection, or kept in the Linux Secret Service (gnome-keyring or KWallet). Without a Secret Service the key cannot be saved at all rather than falling back to a plain file. It is never written into project files or the app bundle.
  • Removing the app does not delete your working data; to erase it, quit the app and delete the folders above.

Privacy commitments

  • Local first: recording and recovery work without signing in or going online.
  • Original screenshots, closing photos, file contents and clipboard text are never uploaded.
  • Only when you have set your own key and trigger an analysis are the OCR text recognised on your device, the activity timeline and the app name sent to an AI service (currently DeepSeek). OCR text can contain sensitive information; decide per project whether to allow it.
  • Usage telemetry is off by default; data sync is optional and not yet open in the clients. Before turning it on you must explicitly consent to "Data sync" (withdrawable at any time), synced content is end-to-end encrypted, and the server stores only ciphertext.
  • Accounts are optional, managed by a self-hosted Logto sign-in service, and offer email-and-password sign-in only; signing in does not make the client upload your data automatically.

See the full Privacy Policy (draft).

FAQ

Do I need an account?

No. Every local feature works without signing in, and signing in does not make the client upload your data automatically. Accounts are optional and are for managing your profile, authorized devices, consents, data export and deletion. Sign-in is email and password only: signing up is verified with an email code and a forgotten password is reset with an email code. Phone-number sign-in, third-party sign-in (Apple, Google, GitHub and the like) and multi-factor authentication are not offered. In the Linux, Android and Windows clients choose Sign in in Settings and finish device authorization in your browser; the macOS client does not support sign-in yet. Manage your account on the account page.

Why is nothing available on the download page?

That platform has no published release yet, or every release is still a prerelease (turn on "Show beta builds" on the download page). The page honestly shows "Nothing to download yet" and never invents a version. Please check back later.

Windows shows "unknown publisher".

The program is not code-signed yet, so SmartScreen may warn. Verify the SHA-256 from the download page before running it.

What do the AI features need?

Your own DeepSeek API key; you are responsible for that service's fees and terms. Without a key or when offline, a local hand-off summary is still produced and pending analysis resumes once you are online.

On Linux, a library is missing or there is no Secret Service. What now?

Install the libraries listed under Install; to save an AI key, install and unlock gnome-keyring or KWallet. Without a Secret Service local records still work, you just cannot save keys or sign-in tokens.

How do I stop recording?

Click Save checkpoint. Hiding the entry or quitting also stops recording. On macOS you can also end it from the menu-bar smiley.

Are there Linux, Android or iOS versions? What about the hardware?

Linux has an early release (x86_64 only; see the one-line installer and known limitations under Install). Android and iOS are unreleased and nothing is offered for download. The physical desk companion is still a concept; the software works on its own without it.

How do I delete my data?

Local data: quit the app and delete the folders listed under Where data is stored. Account data export and deletion are done in the account centre.
