隐私政策

生效日期：2026-10-15

一句话概括

PIXO TAP 是本地优先的软件。截图原图、照片、原文件内容和剪贴板正文只保存在你的设备上，不会上传。账号、同步、遥测和 AI 分析都是可选的：只有你自己配置了 AI 服务密钥并主动触发分析或发起对话时，本机识别出的 OCR 文字、活动时间线文字、对话消息以及自动注入的项目文字摘要与暂放区文件元信息才会直接从你的设备发送给该 AI 服务。同步默认关闭，开启前须你明确同意并设置同步口令或恢复密钥，同步内容全程端到端加密。反馈正文同样端到端加密，服务器只保存密文。

1. 屏幕、键盘与其他采集的范围

  • Windows：只对前台窗口做设备上的文字识别（OCR），并跳过密码输入框。
  • macOS：在你发起的会话中，对整个桌面做设备上的 OCR。开始前会先弹出提示并请求系统的屏幕录制权限。桌面是整屏截取的，请先整理桌面。
  • Linux：在平台允许时，通过系统截图接口截取整屏并做设备上的 OCR。在 GNOME Wayland 下无法读取前台窗口。同样请先整理桌面。
  • 摄像头：只在会话结束时拍一张照片，且只有你开启后才会拍。
  • 键盘输入：不记录。所有端的代码都没有全局键盘钩子。
  • 只有你点击开始后才会记录；每一类采集都需要系统或应用中的授权，并可随时关闭。

4. 同步与遥测

  • 同步默认关闭。客户端默认不同步任何数据；同步须由你主动开启、设置同步口令或恢复密钥并明确同意“数据同步”（sync）。开启后只同步你选择的元数据与文本记录，例如项目结构、恢复笔记、多会话对话、偏好设置和端到端加密的 AI 密钥；不包含截图、照片、原文件正文、剪贴板正文、OCR 全文或活动时间线。同步内容在你的设备上加密后才上传，服务器只保存加密信封，无法解密；未同意或已撤回同意时，服务器拒绝同步请求，明文同步也会被服务器拒绝。
  • 反馈端到端加密。你提交的反馈正文在你的设备上加密，服务器只保存密文，仅发送者本机可以解密。服务端与运营方均无法读取正文；管理后台不显示反馈的任何信息（包括元数据）。我们不会因客服或员工需要处理问题而读取用户内容。
  • 遥测默认关闭。客户端均不开启遥测。服务器只为已明确同意遥测的用户存储遥测记录，并拒绝包含 URL、邮箱、IP 地址或文件路径形式的值。遥测记录不含用户 ID 或任何账号标识，服务器无法把它与你的账号关联：它保留 90 天后自动删除，注销账号时不会按账号删除它，导出也不包含它。你可以撤回同意，撤回后服务器不再接收遥测。

5. 发送给第三方 AI 服务的数据

客户端使用你自带密钥的 AI 服务（目前为 DeepSeek，服务地址为 api.deepseek.com）。只有你配置了密钥并主动开始分析或发起伙伴对话时，才会发送：

  • 设备上识别出的 OCR 文字（经客户端清洗）；
  • 带时间戳的活动时间线文字；
  • 你在聊天框中输入的消息，以及自动注入的项目恢复摘要与暂放区文件元信息（仅文件名、类型与大小）。

不会发送：截图像素、照片、原文件内容、剪贴板正文。OCR 文字本身可能包含敏感信息，请按项目内容决定是否授权分析。发送后的处理受该 AI 服务自身的条款与隐私政策约束，我们无法控制。该服务位于中国，数据传输是因为你选择使用它。没有密钥或离线时，客户端只在本地生成摘要。

本网站不代理 AI 请求。

9. 未成年人

注册账号时，你需要勾选确认已年满 14 岁。这是自我声明，服务器按勾选结果执行，但不做身份核验。未满 14 岁不能使用本服务；我们不提供监护人同意的注册途径。

10. Cookie 与浏览器存储

公开页面（首页、下载、使用说明、隐私政策、用户协议、关于我们）不设置 Cookie，也不加载第三方脚本、字体或跟踪器。浏览器中仅保存 pixo-language（localStorage，语言偏好）与 pixo-selected-pet（sessionStorage，本次会话的桌宠选择）。这些数据不会发送给我们。账号中心与管理后台使用必要的 HttpOnly 会话 Cookie 与 CSRF 令牌维持登录状态，不用于广告或跟踪。

11. 安全措施

  • 密码只保存哈希；登录与验证码请求有速率限制；验证码短期有效。
  • 会话与刷新令牌只保存哈希。
  • IP 地址以带密钥的哈希存储，日志中屏蔽 IPv4 与 IPv6 地址。
  • AI 服务密钥保存在系统钥匙串（macOS）、系统凭据保护（Windows）或系统 Secret Service（Linux），不写入项目文件，也不上传。
  • 待发送的邮件地址与内容加密存储。
  • 同步内容在本机加密后才上传，密钥只留在本机；服务器只保存密文，无法解密。
  • 反馈正文端到端加密，仅发送者本机可解；服务端与运营方均不持有能解密反馈的私钥，管理后台不显示反馈的任何信息（包括元数据）。
  • 下载页使用内容安全策略（CSP）。

我们采取这些措施降低风险，但没有任何系统绝对安全。请妥善保管你的设备与密钥。

Privacy Policy

Effective date: 2026-10-15

In one paragraph

PIXO TAP is local-first software. Original screenshots, photos, original file contents and clipboard text stay on your device and are never uploaded. Accounts, sync, telemetry and AI analysis are all optional: only when you have configured your own AI service key and trigger an analysis or chat is the OCR text recognised on your device, the activity timeline text, or your chat messages and auto-injected project summary / shelf file metadata sent directly from your device to that AI service. Sync is off by default; before you can turn sync on you must explicitly consent and configure a sync passphrase or recovery key, and synced content is end-to-end encrypted. Feedback text is also end-to-end encrypted, and the server stores only ciphertext.

1. Scope of screen, keyboard and other collection

  • Windows: on-device text recognition (OCR) of the foreground window only, skipping password fields.
  • macOS: during a session you start, on-device OCR of the whole desktop. Before it starts you see an alert and are asked for the system screen recording permission. The desktop is captured in full, so please tidy it first.
  • Linux: where the platform allows it, a full-screen capture through the system screenshot portal, with on-device OCR. On GNOME Wayland the foreground window cannot be read. Again, please tidy your desktop first.
  • Camera: one photo at the end of a session, and only if you have turned it on.
  • Keyboard input: not recorded. There are no global keyboard hooks anywhere in the code.
  • Nothing is recorded until you click start. Each kind of collection needs permission in the system or the app and can be turned off at any time.

4. Sync and telemetry

  • Sync is off by default. The clients do not sync any data unless you turn it on. Turning it on requires you to give your explicit consent to "Data sync" (sync). Even if it is enabled in future, only metadata you choose is synced, such as project structure, recovery notes and settings. It never includes screenshots, photos, original files, clipboard text, full OCR text or the activity timeline. Synced content is encrypted on your device before upload; the server stores only the encrypted envelopes and cannot decrypt them. While consent is missing or withdrawn, the server refuses sync requests, and plaintext sync is rejected by the server.
  • Feedback is end-to-end encrypted. The feedback text you submit is encrypted on your device, and the server stores only ciphertext; only the sender's device can decrypt it. Neither the server nor the operator can read the text. The admin console shows no feedback information at all, including metadata. We do not read user content, including when support or staff need to deal with an issue.
  • Telemetry is off by default. No client enables it. The server stores telemetry only for users who have explicitly agreed to it, and rejects values that look like URLs, email addresses, IP addresses or file paths. Telemetry records are not linked to your account and contain no user ID or other account identifier, so the server cannot connect them to you. They are deleted automatically after 90 days, are not deleted by account, and are not part of the export. You can withdraw your consent, and after withdrawal the server stops accepting telemetry.

5. Data sent to a third-party AI service

The client uses an AI service with your own key, currently DeepSeek (api.deepseek.com). Only when you have configured a key and start an analysis is the following sent:

  • OCR text recognised on your device (sanitised by the client);
  • timestamped activity timeline text.

Never sent: screenshot pixels, photos, original file contents, clipboard text. OCR text may contain sensitive information, so decide per project whether to allow analysis. What happens after it is sent is governed by that AI service's own terms and privacy policy, which we cannot control. The service is located in China, and the transfer happens because you choose to use it. Without a key or when offline, the client only builds a local summary.

This website does not proxy AI requests.

11. Security measures

  • Passwords are stored only as hashes. Sign-in and code requests are rate-limited, and codes are short-lived.
  • Sessions and refresh tokens are stored only as hashes.
  • IP addresses are stored as keyed hashes; logs mask IPv4 and IPv6 addresses.
  • The AI service key is kept in the macOS Keychain, Windows credential protection or the Linux Secret Service, is not written to project files and is never uploaded.
  • Outgoing email addresses and bodies are stored encrypted.
  • Synced content is encrypted on your device before upload, and the keys stay on your device; the server stores only ciphertext and cannot decrypt it.
  • Feedback text is end-to-end encrypted and can be decrypted only on the sender's device; neither the server nor the operator holds a key that can decrypt feedback, and the admin console shows no feedback information at all, including metadata.
  • The download page uses a Content Security Policy (CSP).

These measures reduce risk, but no system is perfectly secure. Please safeguard your devices and keys.
